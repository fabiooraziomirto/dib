## Lifecycle mix (`lifecycle_http/`, `lifecycle_mtls/`; audits 130–131)
Each writer cycles commit → dispute → restore on its own fact, so every request is a state change. Distribution **lowers** state-change throughput (W=50, N=10 vs N=1: 0.15× http, 0.26× mtls) because dispute and restore wait for synchronous fan-out to every site; by the pre-registered rule the shared evidence service is the bottleneck in the W=10–50 cells (1.5–2.9 cores, plateau, client ≤ 0.67 core). At W=100 the service exceeds the client's 5 s timeout in some cells (http: 2,797 timeouts and 385 consequent 409s at N=2; others ≤ 32); W=100 ratios are not interpretable.
